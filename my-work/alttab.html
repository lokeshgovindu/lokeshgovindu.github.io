AltTab

AltTab replaces the Windows task switcher. Hold Alt and tap Tab to see every open window, then type to filter the list by title or by application. The match is fuzzy, so an approximate search string is enough: you land on the right window without remembering its exact title.

Alt + ` (the key above Tab) cycles only the windows of the application you are in, which makes it easy to hop between several editors, browsers or terminals. From the list you can close a window, or terminate its process normally or forcefully, one at a time or all of them, and hide or un-hide windows, all without leaving the keyboard. A settings dialog with a live preview controls the size, position, transparency, fonts and colours.

  • Fuzzy search across every open window, by title or by application
  • Alt + ` to cycle the windows of the same application
  • Close, terminate, hide and un-hide from the keyboard, one window or all of them
  • Thirty-one built-in themes, with every font and colour configurable
  • All three hotkeys can be re-recorded
  • Full help built in: F1 opens it, and the same pages are on the project site
  • Native C++ / Win32: small, fast, and no runtime to install
