Windows Application

AltTab

AltTab is a powerful, lightweight Windows application written in C++ and the Win32 API that completely reimagines how you switch between open windows. The native Windows task switcher is functional, but limited — AltTab puts you fully in control. Filter through every open window in real time using a fuzzy search algorithm that intelligently matches even approximate input, so you can land on the right window without memorising exact titles.

A dedicated Alt + ` shortcut lets you cycle exclusively through windows belonging to the same application, making it effortless to hop between multiple instances of your editor, browser, or terminal. Right-click context menus put powerful process management at your fingertips — terminate processes, hide windows, or bring them back — without ever leaving the keyboard. Fine-tune the experience to your taste with a rich settings UI that controls font style, background colour, window transparency, and dimensions.

  • Fuzzy search filtering across all open windows — no exact title needed
  • Alt + ` shortcut to cycle windows of the same application
  • Terminate or hide processes with keyboard shortcuts via context menu
  • Fully configurable font, colour, transparency, and window size
  • Lightweight C++ / Win32 — minimal footprint, maximum speed

PresentationAssistant

When you're on stage delivering a live coding session, workshop, or technical demo, your keyboard shortcuts fly by in a blur — leaving your audience guessing. PresentationAssistant solves this elegantly. Every command and shortcut you invoke is displayed on screen in real time, beautifully overlaid over the IDE, so your audience follows every move without missing a beat.

Whether you're refactoring, navigating the editor, or stepping through a debugger, your keystrokes become a visible, educational part of the presentation. Transform passive spectators into engaged learners with zero configuration overhead.

  • Real-time overlay of keyboard shortcuts during live sessions
  • Configurable display duration and visual style
  • Action blocklist to suppress sensitive or internal shortcuts
  • Zero friction — installs and works immediately

VS Extension

DependencyGraph

Large solutions with dozens of interlinked projects quickly become architectural labyrinths. DependencyGraph cuts through the complexity by generating a clean, interactive visual graph of all project dependencies within your Visual Studio solution, letting you understand the entire architecture at a single glance.

Drill down to the deepest transitive references, zoom in on direct project dependencies, or explore the full reference tree — all from within the IDE. Need to share the diagram? Export it to industry-standard DGML or Graphviz DOT formats for inclusion in design documents or team architecture reviews.

  • Interactive dependency graph directly inside Visual Studio
  • Multiple view modes: deepest, all, or project-only references
  • Export to DGML and Graphviz DOT formats
  • Status bar integration showing total project count

VS Extension

CommandPalette

Developers who have used VS Code, Sublime Text, or any JetBrains IDE know the sheer joy of a Command Palette — type a few characters and any action in the editor is instantly at your fingertips. CommandPalette brings that same experience to Visual Studio, an IDE renowned for its power but notorious for its labyrinthine menus.

Invoke the palette with a single shortcut, start typing, and watch as intelligent fuzzy matching surfaces the most relevant Visual Studio commands in real time. No more hunting through nested menus or memorising dozens of keyboard shortcuts — just type what you want to do and press Enter.

  • Instant access to any Visual Studio command via a single shortcut
  • Intelligent fuzzy matching surfaces commands as you type
  • Persists and recalls the previous command for quick re-execution
  • Lightweight, keyboard-first design with minimal distraction

VS Extension

GoToRecentFile

In large codebases, you're constantly bouncing between the same handful of files — the ones you edited this morning, the header you've been tweaking, the test file always open alongside the implementation. GoToRecentFile gives you a fast, searchable interface to jump directly to any recently opened file without ever lifting your hands from the keyboard.

Built with a clean, theme-aware UI that respects Visual Studio's colour themes — light or dark — it blends seamlessly into the IDE and stays out of your way until you need it. Forget hunting through Solution Explorer or clicking through the native "Recent Files" submenu. Your most-visited files are always one keystroke away.

  • Searchable recent files list accessible via a keyboard shortcut
  • Respects Visual Studio's light and dark colour themes
  • Deduplication — no repeated entries for the same file
  • Seamless VSIX integration with the Visual Studio IDE
