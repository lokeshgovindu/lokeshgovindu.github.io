What changed, what was fixed, and which download to take. description: Release notes for every version of PasteJump, the keyboard-first clipboard manager for Windows, newest first. --- {%- comment -%} OWNED BY THIS REPOSITORY, not synced: script/sync-app-docs.ps1 lists it under Preserve, so a sync neither overwrites nor deletes it. Everything else in this folder is the application repository's docs/release-notes/.md, which _config.yml gives the pastejump-release layout. "What's new" on PasteJump's own website links here, which is why this page exists: until 2026-10-04 that link opened the folder's README, the pipeline's note on how it reads these files. Order is by version, built as a sort key per file because a plain sort of the names puts 2026.3.1 before 2026.3 ("1" sorts before "m" of ".md"). Each part of the version is padded to four digits, and a final release sorts after its own pre-releases: 2026.1-pre6 < 2026.1 < 2026.3 < 2026.3.1. The notes are read with include_relative, so they are rendered from the file itself rather than from another page's content, whose state depends on the order Jekyll happens to render pages in. {%- endcomment -%} {%- assign keys = "" | split: "" -%} {%- for p in site.pages -%} {%- comment -%} By source path: with pretty permalinks a page's dir is its URL, /PasteJump/release-notes/2026.3.1/. {%- endcomment -%} {%- assign p_folder = p.path | split: "/" | pop | join: "/" -%} {%- if p_folder == "PasteJump/release-notes" and p.ext == ".md" and p.name != "README.md" -%} {%- assign v = p.name | remove: ".md" -%} {%- assign split = v | split: "-pre" -%} {%- assign nums = split[0] | split: "." -%} {%- assign key = "" -%} {%- for i in (0..2) -%} {%- assign n = nums[i] | default: "0" | prepend: "0000" | slice: -4, 4 -%} {%- assign key = key | append: n | append: "." -%} {%- endfor -%} {%- if split.size > 1 -%} {%- assign pre = split[1] | prepend: "0000" | slice: -4, 4 -%} {%- assign key = key | append: "0-" | append: pre -%} {%- else -%} {%- assign key = key | append: "1-0000" -%} {%- endif -%} {%- assign key = key | append: "|" | append: p.name -%} {%- assign keys = keys | push: key -%} {%- endif -%} {%- endfor -%} {%- assign keys = keys | sort | reverse -%} {%- assign stable = "" | split: "" -%} {%- assign previews = "" | split: "" -%} {%- for k in keys -%} {%- assign name = k | split: "|" | last -%} {%- if name contains "-pre" -%}{%- assign previews = previews | push: name -%}{%- else -%}{%- assign stable = stable | push: name -%}{%- endif -%} {%- endfor -%}
