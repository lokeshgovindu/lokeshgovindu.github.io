**Hold <kbd>Ctrl</kbd>, tap <kbd>V</kbd> to walk back through what you have copied, release to paste.** No window, no mouse, no hands leaving the keyboard. That gesture is the whole of the idea; everything else exists to support it.

This is the second release of 2026. It fixes a bug that stopped some pictures pasting at all, and adds three things you can do that `2026.1` could not.

[The website](https://pastejump.sourceforge.io/) shows it in a minute. The manual is [readable online](https://pastejump.sourceforge.io/help/overview.html) as well as shipping inside the program, and there is [an architecture reference](https://pastejump.sourceforge.io/architecture.html) if you want to see how it works.

Take the first unless you have a reason not to. Windows 10 or 11, 64-bit. Nothing is installed and nothing is written outside the folder you unzip into, unless you move the data location yourself. The same files are mirrored, byte for byte, to [SourceForge](https://sourceforge.net/projects/pastejump/files/).

Your history and settings carry over — unzip over the old copy, or point the new one at the same data folder.

## Fixed: a picture copied as PNG could not be pasted

Some applications put a picture on the clipboard as a **PNG and nothing else** — WhatsApp, Edge and Windows Terminal all do it for certain copies. Windows does not fill the gap for them, so PasteJump saw no bitmap, filed the copy as `[binary]`, and later — once it had learnt to recognise the picture — showed it in the overlay and then handed the target application a clipboard it could not paste from.

Both halves are fixed. Such a clip is recognised as a picture, previewed, exported and edited as one, and on the way to the clipboard it gains a bitmap decoded from the PNG so anything can paste it. Clips already captured are repaired at start-up.

## New: three things you can do

- **<kbd>L</kbd> locks the overlay open.** Ctrl stops holding the session together: let go and browse, search, tag or read a preview with both hands free. <kbd>Enter</kbd> pastes, <kbd>Esc</kbd> closes, and pressing <kbd>L</kbd> again with Ctrl held unlocks it. It also makes pasting several clips in a row comfortable, which previously meant holding Ctrl throughout.
- **<kbd>?</kbd> lists every key at the bottom of the overlay.** Unlike <kbd>F1</kbd> it opens no window and does not end the session, so the keys it names can be tried as you read them. The list is built from your own bindings, so a letter you have moved shows where you moved it.
- **The overlay says what kind of clip it is.** The row under the preview now reads *what it is, the facts about it, and when it was copied* — `Text · 6 lines, 119 characters`, `Image · 895 × 462 · 1.6 MB`, `Files · 3 files, 1 folder`. The same words the history window uses. Switch it off under **Appearance** if you would rather not have it.

## Present but switched off: typing a clip out instead of pasting it

For fields that refuse a paste — a card-number box that blocks <kbd>Ctrl</kbd>+<kbd>V</kbd> in script, an installer that wants a licence key typed — PasteJump can type a clip out as individual keystrokes, touching the clipboard not at all.

**It ships with no letter assigned, and where it works is now known precisely.** Typed into an ordinary Windows dialog or text box — the kind an installer, a licence prompt or a remote-desktop client puts in front of you, which is exactly where a paste gets refused — a six-line clip arrives **exactly**, over repeated runs. Typed into **Windows 11 Notepad or VS Code** it loses characters however slowly it is fed: both draw their own text through an asynchronous input pipeline that discards injected keystrokes while it redraws, and no pacing fixes that.

So the action is there and unbound rather than removed. Give **Type the clip out** a letter on the **Keys** tab if the places you need it are ordinary dialogs — and do not judge it by trying it in Notepad, which is the one target known to mangle it. It carries a length limit, and <kbd>Esc</kbd> stops one in progress.

## Also

- The footer's <kbd>F1</kbd> reminder is now <kbd>?</kbd>, which answers the same question without opening a window. <kbd>F1</kbd> still works and is still listed in the key card and the `?` list.
- **Longest Clip To Type Out** on the Paste Mode tab, and `typeOutCharDelayMs` in `PasteJump.json` for a window that drops fast input.
- **The search box has its own footer** now — arrows step the matches, <kbd>Enter</kbd> pastes, <kbd>Ctrl</kbd>+<kbd>F</kbd> closes it. It used to keep showing the lettered keys, none of which act while you are typing a query.
- The manual gained sections for all of the above, with pictures.
