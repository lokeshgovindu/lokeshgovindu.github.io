Greenshot
getgreenshot.org
Free & Open Source

A minimal, rock-solid screenshot tool that integrates with the PrintScreen key. Capture a region, annotate it, and send it directly to email, Office, a printer, or a cloud service with a single shortcut. Very low resource footprint.

winget install Greenshot.Greenshot
