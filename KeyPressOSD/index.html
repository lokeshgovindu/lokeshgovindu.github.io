KeyPressOSD Download

See what you press

An on-screen display for keys and mouse buttons on Windows. Shows what you press at a size you can read across a room — for screencasts and presentations, and for anyone who would rather not squint at a text field.

Download for Windows Read the manual

Free and open source under the MIT licence. Nothing is written to disk and nothing is sent anywhere — see Privacy.

What it does

  • Two modes. Keystrokes names each key as you press it. Typing shows the words instead, as one line that never wraps.
  • Reads like a shortcut. Modifiers in a fixed order, named keys drawn as key caps and typed text as plain text, which is what makes a line scannable.
  • Correct on any keyboard layout. Key names come from the layout of the window you are typing into, so AltGr, dead keys and non-US layouts all read correctly.
  • Out of the way. Click-through, never takes focus, absent from Alt+Tab and the taskbar.
