AltTab

A lightweight Windows application written in C++ and the Win32 API that reimagines window switching — fuzzy search filtering, per-application cycling, and right-click process management, all without leaving the keyboard.

  • Fuzzy search filtering across all open windows — no exact title needed
  • Alt + ` shortcut to cycle windows of the same application
  • Terminate or hide processes with keyboard shortcuts via context menu
