Native Desktop Tools

Windows Application

AltTab

A lightweight replacement for the Windows task switcher, written in C++ and the Win32 API. Hold Alt, tap Tab, and type to filter every open window with fuzzy matching, then switch, close or terminate without leaving the keyboard.

  • Fuzzy search filtering across all open windows, no exact title needed
  • Alt + ` to cycle the windows of the same application
  • Thirty-one built-in themes, and every hotkey can be re-recorded

PasteJump

A jog wheel for your clipboard. Hold Ctrl, tap V to walk back through what you copied, and let go to paste it. The clip appears beside the caret, so your hand never leaves the keyboard and nothing steals focus.

  • The Clipjump gesture, reimplemented and extended
  • A clip stack for pasting and a searchable history, kept apart
  • Join several clips into a single paste
C# .NET 10 WPF

Windows Application

PerchBar

One taskbar button for several apps, including the ones already running, however you started them. Pin a group, click it to switch to or launch any member, and anything you start some other way joins the group's button by itself.

  • Adopts windows that are already running, which launchers cannot do
  • Instant, flicker-free, and it survives an Explorer restart
  • One executable, with no installer and no service
C++20 Win32 API Windows Shell

Windows Application

KeyPressOSD

An on-screen display for keys and mouse buttons, at a size you can read across a room. It is built for screencasts and presentations, and is correct on any keyboard layout.

  • Keystrokes mode names each chord; Typing mode shows the words on one line
  • Repeats collapse into a count, such as Alt+Tab x3
  • Click-through, never takes focus, and writes nothing you type to disk
C# .NET 10 WPF
