Terminal Tips

Command Prompt

Useful commands and tricks to master the Windows Command Prompt and work faster from the terminal.

Command History

Cycle through previously executed commands without re-typing them.

↑ / ↓ Arrow Keys
Open Explorer Here

Launch Windows Explorer in the current working directory directly from CMD.

start .
List Directory Tree

Display the entire folder structure as an ASCII tree, including all files.

tree /f /a
Copy Output to Clipboard

Pipe any command's output directly into the clipboard for immediate pasting elsewhere.

<cmd> | clip
Filter Output with findstr

Search command output for lines containing a specific keyword or pattern.

<cmd> | findstr "text"
Full Network Configuration

Display all IP addresses and detailed adapter configuration for every interface.

ipconfig /all
List Running Processes

View all currently running processes and their PIDs to identify resource usage.

tasklist
Kill a Process

Force-terminate a process by its name or PID without opening Task Manager.

taskkill /f /im name.exe
Find Files Recursively

Search for all files matching a pattern across the current directory and all subdirectories.

dir /s /b *.txt
Clear the Screen

Wipe the terminal output for a clean workspace without closing the window.

cls
List Environment Variables

Print all environment variables set in the current session to inspect paths and settings.

set
Create Nested Directories

Create multiple levels of directories in one command without creating them one by one.

mkdir a\b\c
